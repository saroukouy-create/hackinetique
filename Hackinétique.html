Présentation générale du programme

HACKINÉTIQUE est un parcours de formation progressif conçu pour amener un débutant complet, n'ayant jamais programmé ni configuré un système, jusqu'au niveau d'un analyste junior en cybersécurité capable d'auditer, de défendre et de documenter un système d'information réel. Le programme s'étale sur 24 semaines, réparties en 4 phases cumulatives : chaque phase s'appuie sur les compétences acquises dans la précédente.

La logique pédagogique est « construire → casser → défendre → documenter », comme dans les certifications internationales (CompTIA Security+, eJPT, CEH).

🎯 Public cible

  • • Étudiants en informatique, réseaux ou télécommunications.
  • • Jeunes diplômés en reconversion professionnelle.
  • • Passionnés autodidactes avec un ordinateur personnel.
  • • Membres du CJEPE-Bénin souhaitant développer une compétence technique.

📋 Prérequis

  • • Aucun prérequis technique : programme niveau zéro.
  • • Ordinateur avec 8 Go de RAM minimum.
  • • Connexion internet stable.
  • • Niveau de lecture en anglais technique.

🎯 Objectifs globaux

  • • Maîtriser Linux et le développement web (HTML/CSS).
  • • Comprendre l'architecture des réseaux (TCP/IP, DNS, HTTP).
  • • Utiliser les outils de test d'intrusion (Nmap, Metasploit, SQLmap).
  • • Mettre en place une défense (SIEM, IDS) et produire des rapports.

📖 Glossaire de démarrage

Terme Explication simple
Système d'exploitation (OS)Le programme principal qui fait fonctionner un ordinateur (Windows, macOS, Linux).
TerminalUne fenêtre où l'on tape des commandes en texte. L'outil de travail principal d'un informaticien de sécurité.
Machine virtuelle (VM)Un « ordinateur dans l'ordinateur » : logiciel qui simule un second ordinateur complet, isolé du vôtre.
RéseauL'ensemble des connexions qui permettent à des ordinateurs de communiquer entre eux.
ServeurUn ordinateur qui « sert » des informations à d'autres ordinateurs.
VulnérabilitéUne faiblesse dans un logiciel ou une configuration qui pourrait être exploitée.
ExploitUne méthode qui profite d'une vulnérabilité pour obtenir un résultat.
Hacking éthiqueTester la sécurité d'un système avec autorisation, dans le but de le protéger.
CTF (Capture The Flag)Un jeu-concours de cybersécurité pour s'entraîner sans risque.

Pourquoi utiliser Ubuntu sous Windows ?

Ubuntu offre un environnement Linux complet sans remplacer Windows grâce à WSL (Windows Subsystem for Linux). VS Code se connecte directement à cet environnement Linux.

Installation pas à pas

Étape 1 : Installer VS Code

Téléchargez et installez Visual Studio Code depuis code.visualstudio.com.

Étape 2 : Installer WSL

Ouvrir PowerShell en administrateur :

wsl --install

Redémarrer le PC.

Étape 3 : Installer Ubuntu

Vérifier :

wsl --list

Installer Ubuntu si nécessaire :

wsl --install Ubuntu

Créer un utilisateur Linux et un mot de passe.

Étape 4 : Mettre Ubuntu à jour

sudo apt update
sudo apt upgrade -y

Étape 5 : Installer les outils

sudo apt install git curl wget unzip build-essential python3 python3-pip -y

Étape 6 : Installer l'extension VS Code

Dans VS Code : Extensions → Installer WSL.

Étape 7 : Ouvrir Ubuntu dans VS Code

Depuis Ubuntu :

code .

VS Code démarre directement dans l'environnement Linux.

Fondamentaux des réseaux et systèmes

Comprendre les modèles OSI (7 couches) et TCP/IP (4 couches) est indispensable : physique, liaison, réseau (IP), transport (TCP/UDP), application (HTTP, DNS, SSH, etc.).

Architecture réseau

  • Internet → Routeur → Pare-feu → Switch → Serveurs → Clients.
  • Utiliser le plan d'adressage IP, les VLAN, le routage et le DNS pour sécuriser le réseau.

Sécurité système

Mettre à jour Ubuntu, appliquer le principe du moindre privilège (sudo), utiliser SSH avec clés, configurer un pare-feu (UFW), surveiller les journaux (journalctl) et sauvegarder régulièrement.

Langages à maîtriser

Bash (administration) Python (automatisation) PowerShell (Windows) SQL YAML (Docker/Kubernetes) HTML/CSS/JavaScript (Web) Go ou Rust (optionnel)
